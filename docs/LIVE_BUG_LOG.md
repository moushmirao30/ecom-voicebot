# ShopMax — live-deploy bug log (L1–L20)

Twenty bugs found by driving the **deployed** stack (LiveKit Cloud agent + Vercel frontend) with real voice and chat sessions, July 2026. Each row gives the symptom as it appeared live, the root cause, the fix, and the regression test that now guards it. All fixes are on the current code; the full suite is **70 passed** (57 network-free unit + 13 live-LLM evals).
